实验 2 · 触发器时序图（DE ①）

点输入波形的格子改 0/1，看 Q 怎么走

D、T、JK 是同步器件，只在时钟上升沿（虚线）采样输入；SR 是异步的，没有时钟，输入一变输出立刻跟着变（本课规定 S = R = 1 时置 1）。每一格是一个时钟周期。

转移方程
激励表 0→0 / 0→1 / 1→0 / 1→1
Q 翻转次数

看点：JK 里 J = K = 1 每个上升沿都翻转，等于 T = 1；J = 1、K = 0 置 1，等于 D = 1。这就是为什么 JK 能「冒充」其他触发器，激励表里的 X 也最多。

实验 4 · 静态冒险（DE ③）

T = AB + A̅C：理论上一直是 1，实际会闪一下 0

令 B = C = 1，A 从 1 变 0 再变回 1。逻辑上 T 始终为 1，但反相器有延迟：AB 已经掉到 0 时，A̅C 还没升起来，中间 T 掉成 0。加上跨在两个圈之间的质蕴含项 BC（与 A 无关），毛刺就消失了。

结论

为什么同步 FSM 不在乎：毛刺在下一个时钟沿之前就结束了，触发器看不到；AFSM 的输出直接反馈，一个毛刺就可能让机器跳到错误状态，所以 AFSM 要用全部质蕴含项。
