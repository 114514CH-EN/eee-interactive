实验 1 · 一阶滤波器（Lecture 2–3）

本质是分压器：电抗随频率变，输出跟着变

选电路类型、元件值和信号频率。左边是 Bode 图（实线是真实响应，虚线是两条渐近线，交点就是 fc），右边是相量图：输入电压 = 串联元件上的电压 + 输出电压，两者始终垂直。

三个区域：通带里 |H| ≈ 1、相位 ≈ 0；f = fc 时 |H| = 0.707（−3 dB，功率减半），相位 ∓45°；阻带里每十倍频降 20 dB（每倍频 6 dB），相位趋向 ∓90°（低通滞后、高通超前）。RC 和 RL 只是 fc 公式不同：1/(2πRC) 与 R/(2πL)。

实验 2 · 串联 RLC 谐振（Lecture 4–5）

XL = XC 时电抗抵消，只剩 R：电流最大，L、C 上的电压是电源的 Q 倍

电源 1 V。左边是电流幅值随频率（对数轴），绿色区域是 −3 dB 带宽；右边是此刻的电压相量：VL 向上、VC 向下，VR 与电流同相，三者相加等于电源。

f₀ = 1 / 2π√(LC)
Q = (1/R)√(L/C)
带宽 f₀ / Q（f₁ … f₂）
此刻 |I| / |VL| / |VC|

为什么 Q 是电压放大倍数：谐振时 I = Vs/R，VL = I·ω₀L = Vs·ω₀L/R = Q·Vs。VL 和 VC 一样大但反向，在电源两端看不到它们——这就是收音机用很小的天线电压也能在 LC 上得到大信号的原因。
