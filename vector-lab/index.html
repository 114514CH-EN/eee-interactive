实验 1 · 偏导数、驻点与 D 判别式（Week 7）

偏导数 = 切一刀以后的斜率

左图是 f(x, y) 的等高线图（颜色越暖越高）。拖动点 P：橙色横线是固定 y 切下去的那条曲线，它在 P 的斜率就是 ∂f/∂x；蓝色竖线固定 x，斜率是 ∂f/∂y。白圈是驻点（两个偏导都为 0），按 D 判断类型。

D = f_xx f_yy − f_xy²

判别：先解 ∂f/∂x = 0、∂f/∂y = 0 找驻点，再在驻点算 D。D > 0 且 f_xx > 0 → 极小；D > 0 且 f_xx < 0 → 极大；D < 0 → 鞍点（「同号也是鞍点」：f_xx、f_yy 都是 2，但 f_xy = 3 太大，D = 4 − 9 < 0）。只看 f_xx、f_yy 的符号不够，讲义第 36 页专门提醒了这一点。
