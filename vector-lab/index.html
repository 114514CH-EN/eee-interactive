向量微积分实验室

偏导数是曲面沿 x、y 方向切一刀后切线的斜率；驻点处两个偏导都为 0，用 D = fxxfyy − fxy² 判断极值还是鞍点；梯度指向上升最快的方向，方向导数是它在某个方向上的投影；线积分是沿路径把 F·dr 加起来，保守场只看起点和终点；二重积分先切条再把条加起来，可以算面积、形心和二阶矩。对应 B · Week 7 起的向量微积分。

实验 1 · 偏导数、驻点与 D 判别式（Week 7）

偏导数 = 切一刀以后的斜率

左图是 f(x, y) 的等高线图（颜色越暖越高）。拖动点 P：橙色横线是固定 y 切下去的那条曲线，它在 P 的斜率就是 ∂f/∂x；蓝色竖线固定 x，斜率是 ∂f/∂y。白圈是驻点（两个偏导都为 0），按 D 判断类型。

P
∂f/∂x（橙线斜率）
∂f/∂y（蓝线斜率）
f_xx, f_yy, f_xy
D = f_xx f_yy − f_xy²

判别：先解 ∂f/∂x = 0、∂f/∂y = 0 找驻点，再在驻点算 D。D > 0 且 f_xx > 0 → 极小；D > 0 且 f_xx < 0 → 极大；D < 0 → 鞍点（「同号也是鞍点」：f_xx、f_yy 都是 2，但 f_xy = 3 太大，D = 4 − 9 < 0）。只看 f_xx、f_yy 的符号不够，讲义第 36 页专门提醒了这一点。

实验 2 · 梯度与方向导数（Week 7）

梯度指向上坡最陡的方向

紫色箭头是梯度 ∇f，总是垂直于等高线、指向上坡。橙色箭头是你选的单位方向 â。方向导数 df/ds = â·∇f = |∇f| cos θ，θ 是两个箭头的夹角：顺着梯度走最大，沿等高线走为 0，反着走最小。右图画出 df/ds 随方向的变化。

P
∇f at P
|∇f|（最大变化率）
â
df/ds = â·∇f

三步走：① 求 ∇φ = (φ_x, φ_y, φ_z) 并代入点 P；② 方向向量 A 先除以 |A| 变成单位向量 â（最容易忘）；③ 点乘 â·∇φ。问「哪个方向变化最快」：就是 ∇φ 自己的方向，最大变化率是 |∇φ|。

实验 3 · 线积分与做功（Week 8）

线积分 = 沿路径把 F·dr 一小段一小段加起来

灰色小箭头是力场 F。小球沿选中的路径从起点走到终点：橙色箭头是所在处的 F，蓝色箭头是前进方向 T（切线）。每走一小步，做功 F·dr = |F||dr| cos θ：顺着 F 走为正（路径画成绿色），逆着 F 走为负（红色）。右图是累计做功，曲线最后的高度就是线积分 W = ∫F·dr。换一条路径，或者拖动紫色控制点自己弯一条，看 W 变不变。

W（当前路径）
走到 t 时已做功
此处 F·T（每走 1 单位做的功）
回路 ∮ = W① − W②

先判断保不保守：二维力场 F = P i + Q j，算 ∂Q/∂x − ∂P/∂y。处处为 0（区域里没有挖掉的洞）→ 保守场，F = ∇φ，W = φ(终点) − φ(起点)，走哪条路都一样，绕一圈回来 ∮ = 0。不为 0 → W 和路径有关，只能把路径参数化再积分。这个判别式是补充内容（讲义没讲），Week 10 的旋度会正式讲。

实验 4 · 二重积分：先切条，再把条加起来（Week 9）

二重积分 = 先切条，再把条加起来

左图的区域切成 N 条。竖着切（dy dx）：每一条 x 固定，y 从下边界积到上边界，得到这一条的值 S(x)；再把所有条沿 x 加起来。横着切（dx dy）就反过来。右图画的是每一条的值：它下面的面积就是二重积分。被积函数选 1 得面积，选 x、y 得一阶矩（除以面积就是形心），选 y²、x² 得二阶矩 I_xx、I_yy。

I_xx = ∬y² dA

换积分次序：结果不变（讲义「Does order matter? No, just get limits right」），但上下限要重写：竖条的内层限是「下边界 y = … 到上边界 y = …」（x 的函数），外层是常数；横条反过来，有时一种切法要拆成两段（x² 与 x + 2 的横条在 y = 1 处要拆）。最外层的上下限一定是常数。
