实验 1 · 叠加原理（Lecture 3）

两个电源一起作用 = 各自单独作用的结果相加

电路：Va — Ra — 节点 X — Rb — Vb，X 经 Rx 接地。点按钮关掉某个电压源（换成短路导线），看 Vx 的两部分怎样相加。

只有 Va：Vx′
只有 Vb：Vx″
相加 Vx′ + Vx″
两个源一起（直接用 KCL 算）

关掉一个源：电压源 → 短路（V = 0 就是一根导线）；电流源 → 开路（I = 0 就是断开）。只对线性电路成立；功率不能叠加（P ∝ V²）。

实验 2 · 戴维宁与诺顿等效（Lecture 3）

从 A、B 两端看进去，复杂电路 = 一个电压源串一个电阻

原电路：Vs 经 R1 到节点 X，X 经 R2 接地，再经 R3 到端口 A（B 接地）。改负载 RL，比较原电路和戴维宁等效给出的端口电压、电流：永远一样。右图是端口的 V–I 直线（截距就是 VTH 和 IN）。

VTH（开路电压）
RTH = RN（关掉源后看进去）
IN（短路电流）= VTH/RTH
接 RL：原电路 / 等效电路

步骤：① 端口开路求 VTH（R3 没电流，VTH = X 点电压）；② 关掉所有独立源求 RTH = R3 + R1∥R2；③ 诺顿：端口短路求 IN，RN = RTH。三者满足 VTH = INRTH，可以互相检查。

实验 3 · 节点电压法（Lecture 5）

按检查法写电导矩阵 G，解 GV = I

课上例子：50 V — 10 Ω — 节点 2 — 20 Ω — 节点 3 — 30 Ω — 100 V，节点 2 经 15 Ω 接地，节点 3 经 25 Ω 接地（I1 流过它）。把电压源和串联电阻换成诺顿电流源（V/R 并 R），矩阵就能直接看出来。

I1 = V3/25 Ω
检查：节点 3 KCL 残差

检查法：对角 Gkk = 接在节点 k 上所有电导之和（正）；非对角 Gkj = −（节点 k、j 之间的电导）；右边 Ik = 流进节点 k 的源电流。网孔法完全对偶：对角是网孔电阻之和，非对角是 −共享电阻，右边是网孔里电压源的代数和。
