实验 1 · Week 3 · Huffman Coding Tutorial Question / Further Thoughts

收到一串比特，怎么切开？前缀码只有一种切法

讲义 Tutorial：码表 A=0、B=10、C=110、D=111，收到 00100111010，能唯一解码吗？任何码字都不是别的码字的前缀，所以从左往右读，凑够一个码字就切一刀，不会切错。点任意一个比特把它翻转，模拟信道误码，看变长码会怎样「失步」。再换成讲义里那个「打破熵极限」的码 A=0、B=1、C=00、D=01，看 0001 有几种读法。

    平均码长 L̄ = Σ p·ℓ
    信源熵 H（0.55 / 0.3 / 0.1 / 0.05）1.544 bit
    效率 H / L̄
    这一串

    Tutorial 答案：00100111010 = 0|0|10|0|111|0|10 = AABADAB，唯一。问题：一个比特错了，后面的切点全跟着错（误码传播），甚至解出的符号个数都变了；定长码错一位只坏一个符号。好处：平均 1.6 bit/符号，比定长的 2 bit 省 20%，离熵 1.544 只差一点。A=0 B=1 C=00 D=01 平均只要 1.15 bit，看起来低于熵，但 0001 有好几种读法，根本没法用——任何看似打破熵极限的码都是这样。

    实验 2 · Week 3 · Source Coding: Further Thoughts

    把几个符号打包再编码：平均码长从上方逼近熵

    单个符号编码时每个码字至少 1 bit，信源很偏时浪费很大（比如 0.9 / 0.1 的二元信源熵只有 0.469 bit，单独编码却要 1 bit）。把 n 个符号当成一个「大符号」做 Huffman，平均每个原符号的比特数 L̄n/n 落在 H 和 H + 1/n 之间，n 越大越接近熵。这不是打破熵极限，只是换了个统计模型。

    分组概率Huffman 码字
    熵 H
    n = 1：L̄₁
    当前 n：L̄n/n
    效率 H/(L̄n/n)

    为什么有上界 H + 1/n：对 n 个符号的分组，最优码满足 nH ≤ L̄n < nH + 1（多出来的不到 1 bit 来自码长必须是整数），除以 n 就得到每个原符号的界。均匀分布时 H = 2 bit 正好是整数，n = 1 就已经 100%。真实文本里相邻符号还不独立（q 后面几乎总是 u），zip 之类的压缩利用的就是这种相关性。

    实验 3 · Generic Models & Channel Capacity · Useful Equations

    香农容量 C = B log₂(1 + S/N)：带宽是线性的，信噪比是对数的

    C 是在带宽 B、信噪比 S/N 下能做到无差错传输的最高比特率。左图固定 B 看 S/N：高信噪比时每多 3 dB 只多 1 bit/s/Hz。右图固定信号功率 S 和噪声谱密度 N₀（N = N₀B）只加带宽：噪声也跟着变大，容量趋于上限 1.44·S/N₀。

    S/N（倍数）
    容量 C
    频谱效率 C/B
    带宽翻倍（N₀ 不变）/ S/N 翻倍
    带宽无限大时的上限 S/(N₀ ln2)

    换底：计算器没有 log₂ 时用 C = B·log₁₀(1+S/N)/log₁₀2（讲义写法）。记两个数：S/N = 0 dB 时 C = B；S/N 很大时 C ≈ B × S/N(dB)/3.01。电话线 3.1 kHz、30 dB：C = 3100 × log₂1001 ≈ 30.9 kbit/s，这就是老式拨号调制解调器卡在 ~33.6 kbit/s 附近的原因。

    实验 4 · Wireless: Antennas & Propagation · Useful Equations

    链路预算：自由空间每十倍距离掉 20 dB，贴地传播掉 40 dB

    自由空间 Pr = PtGtGr(λ/4πd)²；在导电地面上方，直射波和地面反射波干涉，远处变成 Pr = PtGtGr(hthr/d²)²。用 dB 写就是一路加减。蓝线自由空间，橙线是地面双径的精确干涉（细线）和讲义近似（粗虚线），两者在 d ≫ 4πhthr/λ 后重合。绿线是接收灵敏度。

    波长 λ = c/f
    自由空间路径损耗 20log(4πd/λ)
    Pr：自由空间 / 地面双径
    余量（自由空间 − 灵敏度）
    最远距离：自由空间 / 双径
    转折距离 4πhthr/λ；接收口径 A = Gλ²/4π

    为什么频率高损耗大：不是空气「吸收」得多，而是同样增益的天线在高频时口径 A = Gλ²/4π 更小，接住的能量更少（理想天线 D = 4πA/λ²）。地面双径：远处直射波和反射波几乎等长、反射又反相，二者几乎抵消，所以按 1/d⁴ 衰减，而且和频率无关；把天线架高（hthr 变大）比加功率有效得多——这就是基站要上铁塔的原因。卫星预设里 d = 36 000 km，自由空间损耗约 205 dB，要靠两端的大锅天线补回来。

    实验 5 · Transmitting Analogue Signals by Digital Methods · Useful Equations

    量化噪声：每多 1 bit，SQNR 多 6 dB

    先按 fs > 2Fmax 采样，再把 −A/2 … A/2 等分成 N = 2p 级，每个样本取最近的一级。蓝线是原信号，橙色台阶是量化后的样本，下面红线是量化误差（最大 ±Δ/2）。满幅正弦的 SQNR = 3N²/2，即 6.02p + 1.76 dB；信号比满幅小多少 dB，SQNR 就少多少 dB。

    量化级数 N = 2p / 级间距 Δ = A/N
    SQNR 公式 6.02p + 1.76 + 电平
    SQNR 实测（大量样本）
    比特率 fs × p

    公式从哪来：误差在 ±Δ/2 内均匀分布，功率 Δ²/12；满幅正弦功率 (A/2)²/2 = A²/8；相除并代入 Δ = A/N 得 3N²/2，取 10log₁₀ 就是 1.76 + 6.02p。p = 1 或信号很小时误差不再「均匀」，实测会偏离公式。电话 8 kHz × 8 bit = 64 kbit/s，正好是一路数字电话（PCM）的速率。

    实验 6 · The Effect of Noise · Useful Equations

    噪声里判 0 还是 1：误码率就是高斯尾巴的面积

    发送电平（单极性 0 / A 或双极性 ±A）加上标准差 σ 的高斯噪声，接收端和门限 Vth 比较。把门限归一化成 xth = (Vth − 电平)/σ，错判概率 = 1 − Φ(xth)，就是阴影面积。点「发 2000 个比特」看实际数出的错误和理论是否一致。

    发 0 判成 1：1 − Φ(xth)
    发 1 判成 0
    总误码率（等概率）
    实测（2000 bit）
    电平间距 / σ

    怎么查表：单极性 0/1 V、σ = 0.25 V、门限 0.5 V：xth = (0.5 − 0)/0.25 = 2，P = 1 − Φ(2) = 0.0228；两边对称，总误码率也是 0.0228。门限偏离中点时，一边的尾巴缩小、另一边涨得更快，总和变大。双极性 ±1 V 的间距是 2 V，相当于 xth = 4，误码率降到 3×10⁻⁵——代价是平均功率更大。真正决定误码率的是「电平间距 ÷ 噪声」。

    实验 7 · Digital and Analogue Filters · Useful Equations

    Butterworth 通带最平，Chebyshev 用通带波纹换更陡的过渡带

    Butterworth：|T|² = 1/[1 + (ω/ωc)2n]，通带没有起伏，ωc 处 −3 dB。Chebyshev：|T|² = 1/[1 + ε²Cn²(ω/ωp)]，通带在 1 和 1/(1+ε²) 之间波动 n 次，换来过渡带更陡。设一个阻带指标，看两种各需要几阶。

    ε = √(10波纹/10 − 1)
    ωs 处衰减：Butterworth / Chebyshev
    满足指标的最小阶数：Butterworth / Chebyshev
    远处斜率

    远处都是 −20n dB/十倍频：n 阶滤波器在 ω ≫ ωc 时都按 1/ωn 衰减，Chebyshev 的优势在过渡带——同样阶数下，远处它比 Butterworth 多出约 20log(2n−1ε) 的衰减（ε 小时可能反而不如 Butterworth）。阶数公式：Butterworth n ≥ log(10A/10 − 1)/(2 log(ωs/ωc))，Chebyshev n ≥ cosh⁻¹(√(10A/10 − 1)/ε)/cosh⁻¹(ωs/ωp)。
