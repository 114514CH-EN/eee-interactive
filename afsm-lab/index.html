异步状态机实验室

实验 1 · 继电器 AFSM：河道闸门（DE15）

拖水位、按过流，看接触器和闸门怎么动

完全按 DE15 的结果实现：Raise = Float·SW1̅·Over̅·Lower̅，Lower = Float̅·SW2̅·Over̅·Raise̅。继电器有吸合 / 释放时间，所以「升 → 降」一定先经过「不动」A。限位开关由闸门位置自动触发。右边是梯形图：亮的导线有电，触点画成闭合 / 断开的真实状态。

试一试：① 把水位拖低，看 Raise 先断开、过一会儿 Lower 才吸合（B → A → C）。② 打开「波浪」再关掉「机械滞回」：水位在阈值附近抖，Float 来回跳，电机启动次数猛涨；打开滞回就安静了（DE15 p.11）。③ 闸门运动时按「过流」，两个接触器立刻全断，回到 A。

实验 2 · 多比特变化与虚拟状态（DE16–DE17）

A(00) → C(11) 要变两位：谁先到，机器就去哪

编码 Y1Y0：A = 00，B = 01，C = 11，D = 10（未用）。输入 x 变成 1 时，A 应该去 C；但 B 在 x = 1 时是稳定状态（有 sling）。两个反馈位的延迟不同：Y0 先到，机器经过 01 = B 就停住了。改成「经过虚拟状态 D」：A → D → C，每一步只变一位，延迟怎么配都对。

看点：直接模式下，Y0 比 Y1 快就停在 B，Y1 快就经过 D 到 C——结果取决于门延迟，这就是「关键竞争」。DE16 的规则：AFSM 编码只允许单比特转移，不可避免时借未用的编码做虚拟状态。

实验 3 · 用门电路搭 AFSM 触发器（DE17–DE20）

按讲义方程接成 AND-OR 加反馈，一次只拨一个输入

Qb⁺、Q⁺ 用讲义流表求出的方程实现：每个乘积项一个与门，一个或门，输出直接接回输入。每级门 1 个时间单位，反相器延迟可调。默认用全部质蕴含项（AFSM 规则）；切到「最小和」后，T 和 JK 在某些转移上会因静态冒险跳错。Clk 反相器太慢、或 Clk 脉冲太窄，则是本质冒险。

试一试：① T 型切到「只用最小和」，先拨 T = 1、Clk = 1（到 B），再把 Clk 拨回 0：B 应该去 C（Q 翻成 1），电路却回到 A。看方程里亮着的项：Clk 下降那一刻 Qb⁺ 的项全灭了。切回全部质蕴含项，虚线框的「桥」一直亮着，就对了。JK 在 C、J = K = 1 时拨 Clk 0 → 1 同理。② 本质冒险：把「Clk 反相器延迟」拖到 5 以上，T 型（全部质蕴含项）在 A、T = 1 时拨 Clk 0 → 1 会跳到 D；或者把脉冲宽度调到 1–2 再按「Clk 窄脉冲」，D 型直接漏掉这个时钟沿。
