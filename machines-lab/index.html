实验 1 · 直流电机（Machines 1）

转矩–转速是一条直线：加负载就变慢，提高电压整条线平移

等效电路 Vs = IR + ε，反电动势 ε = κω，转矩 T = κI，所以 T = κ(Vs − κω)/R。蓝线是电机特性，橙线是负载需要的转矩，交点就是稳定运行点。虚线是其他电压下的特性（平行线）。

转速 ω（电机 / 滑轮经 20:1）
电流 I = T/κ，反电动势 ε = κω
输入 VsI / 机械 Tω / 铜损 I²R
效率 η

两个端点：ω = 0（堵转）时转矩最大 κVs/R，电流 Vs/R 全部变成热；T = 0（空载）时 ω = Vs/κ，反电动势正好等于电源电压。用 PWM 改变平均 Vs 就能电子调速。（这里忽略转动惯量，只看稳态。）

实验 2 · 变压器阻抗匹配（Machines 2）

从初级看进去，次级负载变成 Z₂ / n²

放大器（Vs、内阻 Rth）经匝数比 n = N₂/N₁ 的理想变压器接负载 RL。初级看到 Z₁ = RL/n²；当 Z₁ = Rth 时负载功率最大。曲线是 PL 随 n 变化。

Z₁ = RL/n²
I₁ / I₂ = I₁/n
V₁（线圈上）/ V₂ = nV₁
负载功率 PL（最佳 n）

记法：V₂ = nV₁，I₁ = nI₂（功率守恒 V₁I₁ = V₂I₂），所以 Z₁ = V₁/I₁ = (V₂/n)/(nI₂) = Z₂/n²。降压变压器（n < 1）让小阻抗「看起来」变大。

实验 4 · 并励与串励有刷直流电机（Year 2 EM Week 5）

并励：转矩随转速直线下降、转速很稳；串励：起动转矩极大，空载会飞车

都从电枢回路的基尔霍夫电压定律出发：Vs = EA + IARA。并励的磁通恒定，EA = kvω、T = kvIA；串励的磁通跟着电流走，EA = KIω、T = KI²。左图：转矩（蓝）、功率（橙）随转速，橙色横线是负载转矩，红点是运行点。右图：电流（紫）和效率（绿）。「其他损耗」代表铁损（磁滞、涡流）和摩擦。

对照 2026 Q3：kv = (200 − 5×0.4)/188.5 = 1.05；堵转电流 500 A、堵转转矩 525 N·m；空载转速 190.4 rad/s（1818 rpm）；最大功率 V²/4R = 25 kW 出现在一半转速；只算电枢铜损时效率 = ω/ω0，转速越高效率越高。讲义两张图可由「讲义」两个预设复现：并励图是 24 V、1 Ω、kv ≈ 2.88（堵转 24 A、69 N·m，空载 8.33 rad/s，最大功率 144 W）；串励图是 120 V、1.2 Ω、K = 0.048（最大功率 V²/4R = 3 kW 出现在 ω = R/K = 25 rad/s，效率 Kω/(R+Kω) 在 94 rad/s 时 79%）。

实验 5 · 交流感应电机（Year 2 EM Week 7 · Lecture 8）

转子永远比旋转磁场慢一点：转差率 s 决定转矩，也决定浪费多少

三相定子绕组产生转速 ωs = 2πf/P 的旋转磁场（P = 每相极对数）。转子比它慢，转差率 s = (ωs − ωm)/ωs，转子导条里才有感应电流和转矩。简化等效电路（忽略 R1、Xm）：T = V²(R2/s) / [ωs((R2/s)² + X²)]，最大转矩 Tm = V²/(2ωsX) 出现在 s = α = R2/X。左图：转矩–转速（橙线是负载，红点是运行点，绿色区是发电机）。右图：气隙功率 Pag 分成机械功率 (1 − s)Pag 和转子铜损 sPag。

同步转速 ns / 运行转速
转差率 s · 转子电流频率 sf
最大转矩 Tm · 出现在 s = α
Pag / 机械 / 转子铜损 · 转子效率 1 − s

对照习题：100 V、50 Hz、1 对极、X = 1.5 Ω → Tm = 100²/(2 × 314.2 × 1.5) = 10.6 N·m；R2 = 0.5 Ω 时 α = 1/3，堵转转矩 T0 = Tm·2α/(1 + α²) = 6.37 N·m（官方答案写 5.5 N·m，按讲义的 α 定义算不出来）。为什么 s = 0 没有转矩：转子和磁场同速，导条看到的磁通不变，没有感应电动势就没有电流。转差越大越浪费：转子铜损 = sPag，所以感应电机都在小转差（几个百分点）下工作。这里是每相的简化模型，没有算定子铜损、铁损和摩擦。

实验 6 · 永磁无刷直流电机（Year 2 EM Week 8 · Lecture 9）

六步换相：每次只给两相通电，定子磁场一步 60° 地「拉着」永磁转子转

转子是永磁体，定子三相绕组由三相逆变器（6 个开关）供电。转子位置传感器告诉控制器现在该接通哪两相，使定子磁场总是超前转子 60°–120°。任何时刻两相串联、两个开关导通：V = 2VOS + I·2Rph + 2kω，T = 2kI（k 是每相反电动势常数）。所以它的转矩–转速和并励直流电机一样是一条直线；驱动器限流时，低速段被削平，直线和平台的交点就是转折转速 ωc。
