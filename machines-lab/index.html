实验 1 · 直流电机（Machines 1）

转矩–转速是一条直线：加负载就变慢，提高电压整条线平移

等效电路 Vs = IR + ε，反电动势 ε = κω，转矩 T = κI，所以 T = κ(Vs − κω)/R。蓝线是电机特性，橙线是负载需要的转矩，交点就是稳定运行点。虚线是其他电压下的特性（平行线）。

转速 ω（电机 / 滑轮经 20:1）
电流 I = T/κ，反电动势 ε = κω
输入 VsI / 机械 Tω / 铜损 I²R
效率 η

两个端点：ω = 0（堵转）时转矩最大 κVs/R，电流 Vs/R 全部变成热；T = 0（空载）时 ω = Vs/κ，反电动势正好等于电源电压。用 PWM 改变平均 Vs 就能电子调速。（这里忽略转动惯量，只看稳态。）

实验 2 · 变压器阻抗匹配（Machines 2）

从初级看进去，次级负载变成 Z₂ / n²

放大器（Vs、内阻 Rth）经匝数比 n = N₂/N₁ 的理想变压器接负载 RL。初级看到 Z₁ = RL/n²；当 Z₁ = Rth 时负载功率最大。曲线是 PL 随 n 变化。

Z₁ = RL/n²
I₁ / I₂ = I₁/n
V₁（线圈上）/ V₂ = nV₁
负载功率 PL（最佳 n）

记法：V₂ = nV₁，I₁ = nI₂（功率守恒 V₁I₁ = V₂I₂），所以 Z₁ = V₁/I₁ = (V₂/n)/(nI₂) = Z₂/n²。降压变压器（n < 1）让小阻抗「看起来」变大。

实验 3 · 桥式整流与电容滤波（Machines 3）

实验 4 · 并励与串励有刷直流电机（Year 2 EM Week 5）

并励：转矩随转速直线下降、转速很稳；串励：起动转矩极大，空载会飞车

都从电枢回路的基尔霍夫电压定律出发：Vs = EA + IARA。并励的磁通恒定，EA = kvω、T = kvIA；串励的磁通跟着电流走，EA = KIω、T = KI²。左图：转矩（蓝）、功率（橙）随转速，橙色横线是负载转矩，红点是运行点。右图：电流（紫）和效率（绿）。「其他损耗」代表铁损（磁滞、涡流）和摩擦。
