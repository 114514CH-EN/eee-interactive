实验 1 · 傅里叶级数

周期信号 = 直流 + 基波 + 各次谐波；跳变越陡，高次谐波越多

选波形和谐波数 N。左边虚线是目标波形，蓝线是前 N 次谐波之和；右边是单边幅度谱 An（已用到的标蓝）。读数里的「功率占比」用帕塞瓦尔定理：A₀² + ΣAn²/2 除以总平均功率。

为什么三角波收敛快、方波收敛慢：三角波连续，系数按 1/n² 衰减；方波有跳变，系数只按 1/n 衰减，高次谐波还很大。跳变处的过冲约为跳变量的 9%，项数再多也不消失，只是越来越窄。

实验 2 · 矩形脉冲的傅里叶变换

时域越窄，频域越宽；时移只改相位，不改幅度

高度 1、宽 τ 的矩形脉冲，中心在 t₀。X(f) = τ·sinc(fτ)·e−j2πft₀（sinc(x) = sin(πx)/(πx)）。上图是 |X(f)|，下图是相位：t₀ ≠ 0 时相位是一条斜率 −2πt₀ 的直线（跨过零点时跳 180°）。

X(0) = 面积 τ
主瓣第一零点 1/τ
主瓣宽 × 脉宽
相位斜率 −2πt₀

工程意义：数据脉冲越短（比特率越高），占用的带宽越大，约为 1/τ。这就是「时宽 × 带宽 ≈ 常数」。

采样后频谱在 k·fs 处无限复制；fs < 2f 时复制品闯进基带

左边：灰线是原信号，红点是采样值，蓝 / 橙线是从这些点能唯一还原出的、频率在 0…fs/2 内的正弦。右边：采样后的频谱，绿色是能还原的基带 0…fs/2，灰色竖线是复制品 k·fs ± f。

为什么混叠不可逆：1 kHz 和 0.7 kHz 的正弦在 1.7 kHz 采样下得到完全相同的一串数，采完就分不出来了。所以 ADC 前面一定要有抗混叠低通滤波器，先把 fs/2 以上的成分滤掉。
