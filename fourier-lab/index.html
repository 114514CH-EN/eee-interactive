周期信号 = 直流 + 基波 + 各次谐波；跳变越陡，高次谐波越多

为什么三角波收敛快、方波收敛慢：三角波连续，系数按 1/n² 衰减；方波有跳变，系数只按 1/n 衰减，高次谐波还很大。跳变处的过冲约为跳变量的 9%，项数再多也不消失，只是越来越窄。

为什么混叠不可逆：1 kHz 和 0.7 kHz 的正弦在 1.7 kHz 采样下得到完全相同的一串数，采完就分不出来了。所以 ADC 前面一定要有抗混叠低通滤波器，先把 fs/2 以上的成分滤掉。

实验 5 · 常数项为什么是 a₀/2（Maths Part B · Week 4）

cos² nx 的平均高度只有 ½，常数 1 的平均高度是 1：同一个公式用到 n = 0 会多算一倍

左边是「尺子自乘」cos² nx 在一个周期上的面积：n ≥ 1 时只有 π（平均高度 ½），n = 0 时 cos 0 = 1，面积是 2π（平均高度 1）。系数公式前面的 1/π 是按「面积 π」配好的，所以拿它算 n = 0 会得到平均值的 2 倍。右边看结果：红色虚线是直接用 a₀ 当常数项，绿色是 a₀/2，只有绿色正好是 f 的平均高度。

∫ cos² nx dx（一个周期）
a₀ = (1/π)∫ f dx
真正的平均值 (1/2π)∫ f dx
所以常数项

一句话：求 aₙ 时两边乘 cos nx 再积分，右边剩下 aₙ·∫cos² nx dx = aₙ·π，所以除以 π。常数项那一项乘的是 1，∫1·1 dx = 2π，本该除以 2π。课件为了只记一个公式，统一除以 π，代价就是 n = 0 时多了一倍，于是在级数里写 a₀/2 把它除回来。

实验 6 · 常见脉冲的傅里叶变换（Communication Systems · Week 4 第 2 讲）

脉冲边沿越平滑，旁瓣越低；脉冲越窄，频谱越宽

四种脉冲都在 |t| < T/2 内（高斯除外）。左边是 w(t)，右边是 W(f)：矩形 T·sinc(fT)，半余弦 (2T/π)·cos(πfT)/(1 − 4f²T²)，三角 (T/2)·sinc²(fT/2)，高斯 T·e−πf²T²。切到 dB 看旁瓣：旁瓣就是会漏到相邻信道里的能量。

为什么三角的频谱是 sinc²：底宽 T 的三角 = 两个宽 T/2 的矩形卷积（再乘 2/T）。时域卷积 = 频域相乘，所以 sinc 变成 sinc²：旁瓣按 1/f² 衰减，第一零点推到 2/T。
