实验 3 · 最大功率定理（C1 应用）

P = V²RL/(RL + Rs)²：dP/dRL 由正变负的地方（RL = Rs）功率最大

电压源 V 带内阻 Rs，接负载 RL。拖动 RL，看负载功率 P 和导数 dP/dRL = V²(Rs − RL)/(RL + Rs)³ 的符号。效率 = RL/(RL + Rs)，最大功率时只有 50%。

最大可能 V²/(4Rs)

为什么讲师说「不要再求一次导」：二阶导数检验在 f″ = 0 时失效（例如 x⁴ 在 0 处 f″ = 0 却是最小值），而且这里的二阶导数很难算。看一阶导数在驻点左右的符号（+ 变 − 是最大，− 变 + 是最小）总是有效的。
