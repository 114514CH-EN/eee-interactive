## 维护

- 每页的 `?lab=N` 在 Notion 里嵌入时只显示第 N 个实验（`assets/common.js`）；直接打开则滚动到该实验。
- 新增或改名实验后运行 `python3 tools/build_index.py`，首页的分组卡片和实验小标签会按各页 header 里的导航重新生成（分组和一句话简介在脚本顶部的 `GROUPS` / `BLURB`）。
