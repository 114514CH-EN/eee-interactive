实验 1 · 时域里的功率（Lecture 1）

p = v × i：电阻一直在吃能量，电感电容只是借了又还

电压 v = Vp sin ωt，电流比电压滞后阻抗角 φ（φ > 0 是电感性，φ < 0 是电容性）。红色阴影是 p > 0（电源送进负载），蓝色是 p < 0（负载还给电源）。平均值就是有功功率 P，来回流动的幅度就是无功功率 Q。

平均功率 P = ½VpIp cos φ
无功 Q = ½VpIp sin φ
功率因数 cos φ
p 的频率2ω

看点：纯电阻时 p 永远 ≥ 0，平均是 VpIp/2 = VrmsIrms；纯电感、纯电容时红蓝面积相等，平均为 0，能量只是在磁场 / 电场和电源之间来回搬。只看耗散的功会低估电源实际要送出的电流。

实验 2 · 有功、无功、视在功率与功率因数校正（Lecture 2–3）

给电机并一个电容，抵消无功功率，电源电流就变小

电机 = 电阻 + 电感串联，讲义例 1：240 V、5 A、φ = 30°，S = 1200 VA，P = 1039 W，Q = 600 VAr。拖动电容 C，左图是功率三角形（灰色 = 校正前），右图是电流相量。默认并联（实际做法，电机两端电压不变）；切换到串联可以看到为什么不能串联。

并联 vs 串联：并联时电机两端还是 240 V，它的 P、Q 都不变，电容提供 −Q，电源只需要送 P：电流 5 A → 4.33 A（讲义 p.36 的数）。串联时电机电压变了，谐振时电流反而变大（5.77 A），电机吸收的 P 也变了，所以讲义 p.36 的 4.33 A 只对并联成立。

实验 3 · 最大功率传输与效率（Lecture 3）

RL = Rout 时负载功率最大，但效率只有 50%

戴维宁源 VTh 串 Rout 接负载 RL。蓝线是负载功率 PL（横轴对数），橙线是效率 η = RL/(Rout+RL)。

推导：PL = VTh²RL/(Rout+RL)²，对 RL 求导令其为 0 得 Rout = RL。交流时推广成共轭匹配：负载 = Rout − jXout。
