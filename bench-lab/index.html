实验 3 · Lab 1 Experiment 3 · The Capacitor in a Circuit

电容的阻抗 1/(ωC) 随频率变小：输出变小，并且越来越滞后

讲义 Expt 3 用 47 kΩ 和 1 nF，输入 5 V 峰值正弦波，CH1 看输入、CH2 看输出。讲义里 Figure 3 没有附图，这里按最常见的接法把输出取在电容两端（RC 低通），也可以切到电阻两端（高通）比较。量两条波形正向过零点之间的时间差 Δt，相位 = 360° × Δt/T。点「记录这一点」就像往 Excel 表里填一行。

XC = 1/(2πfC)
转折频率 fc = 1/(2πRC)
输出峰值 / 增益
Δt（正 = 输出滞后）
相位 = 360°·Δt/T
fVin 峰值Vout 峰值Vout/VinΔt相位滞后

为什么：R 和 C 串联分压，Vout/Vin = XC/(R + XC)（复数）= 1/(1 + jωRC)。低频时 XC ≫ R，电容几乎「开路」，输出≈输入；f = fc 时 |H| = 1/√2 = 0.707、滞后 45°；高频时电容几乎「短路」，输出趋于 0、滞后趋于 90°。讲义 1 kHz 时 XC = 159 kΩ，所以输出约 4.79 V、滞后约 16°（Δt ≈ 45 µs）。量 Δt 用过零点：那里斜率最大，时间读得最准。

实验 4 · Lab 3 · Thermistor Temperature Sensor

热敏电阻温度计：分压器 + 同相放大器，再把公式倒过来算温度

讲义 Figure 1：+15 V 经 R₁ = 22 kΩ 和热敏电阻 RT 分压得到 V₊，TL071 接成同相放大器，R₂ = R₃ = 4.7 kΩ，增益 1 + R₃/R₂ = 2。RT 用讲义的拟合 R(T) = 13.743 e−0.039T kΩ。拖温度看 Vout 怎么变；在右边输入你实测的 Vout，用公式 (3) 倒推 RT 和温度。

RT = 13.743 e−0.039T kΩ
V₊ / V₋（有负反馈时相等）
Vout
灵敏度 dVout/dT
自热 P = VT²/RT，ΔT = P/(4.5 mW/K)
由 Vout 倒推（公式 3）

两个功能块：分压器给出 V₊ = Vcc·RT/(R₁+RT)，同相放大器乘上 (R₂+R₃)/R₂，合起来就是公式 (1)。倒过来：RT = R₁ / [ (Vcc/Vout)·(R₂+R₃)/R₂ − 1 ]，再由 T = ln(13.743/RT)/0.039 得温度。温度升高 → RT 变小（NTC）→ Vout 下降。拟合式在 25 °C 给 5.17 kΩ，和标称 R₂₅ = 5 kΩ 差 3%，在 ±10% 容差内。排错：若 V₊ ≠ V₋，说明没有负反馈或输出已经饱和（接近电源电压）。

LED 两端电压几乎固定（数据表 VF），电流却随电压指数上升，所以必须用串联电阻限流：I = (Vs − VF)/R。左图蓝线是 LED 的 I–V 曲线，橙线是电阻的负载线，交点就是工作点；右边对照 Kingbright DLA/DLC 数据表的绝对最大额定值。最后一个预设是机器人蛇的红外信标：5 V 经两个 39 Ω 并联。

实验 6 · Lab 5 · The Robot Snake

机器人蛇：RC 放电时间 → 归一化阴影差 → 左右轮速度

每只「眼睛」是一个光敏三极管并联 0.1 µF 电容。Arduino 先把电容充到 5 V，再测它放电到 2.1 V（逻辑低门限）用了多久：光越强，三极管电阻越小，放电越快，t = RptC·ln(5/2.1)。然后算 nshade = tR/(tL+tR) − 0.5，按讲义代码给左右轮速度。点场地任意位置放信标，按「运行」看它追光。

tLeft / tRight
nshade = tR/(tL+tR) − 0.5
speedLeft / speedRight
动作

代码逻辑（Activity 4）：nshade > 0 说明右眼更暗（放电更慢），于是 speedLeft = 200 − nshade × 1000、右轮全速 200，左轮慢、车向左转，朝亮处走；nshade < 0 则反过来减右轮。constrain 把速度限制在 ±200。系数越大，同样的 nshade 造成的速度差越大，转向越猛，也就是系数越大越灵敏（太大会左右摆动）。用的是比值而不是绝对时间，所以整体变亮变暗不影响方向。信标在身后时两只眼睛都看不到它，nshade ≈ 0，车只会直走，碰到墙弹回来才「看见」。这里三极管电阻与光强的关系是示意值。
