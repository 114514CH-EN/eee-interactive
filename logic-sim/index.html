逻辑模拟器

搭门电路、触发器和功能模块，按运行看每根线的 0 / 1 和逻辑分析仪波形。「真值表」会自动出最小和 / 最小积、卡诺图圈组、冒险检测和关键路径；「状态图」把时序电路画成状态转换图并检查锁死；「生成电路」把表达式或真值表直接变成门电路。

模拟器 · 预设对应 DE ①②③、EE1 Digital Fundamentals / Sequential Logic 的例题

    从表达式生成

    一行一个输出。非：A' ~A !A；与：AB A·B A&B；或：+ |；异或：⊕ ^。也可以写 F(A,B,C) = Σm(1,3,5) + d(7) 或 ∏M(0,2)。变量是一个大写字母（后面可以跟小写或数字，如 Cin A1）。

    从真值表生成

    点输出格子切换 0 → 1 → X（无关项）
    实现方式：
    怎么用

    放元件 → 连线 → 运行；或者直接写表达式让它生成

    选工具后在网格上点一下放元件；导线从一点拖到另一点（斜着拖会自动拐直角）。点「开关」切换 0 / 1，键盘上按和开关同名的字母也行。同名的「网络标签」自动相连，不用拉长线。悬停在任意一根线上能看到它的值、谁在驱动它。选中元件后在下方改名字、输入数、门延迟、时钟半周期、触发沿和复位值。

    仿真规则：每个门有自己的传播延迟（默认 1 拍），所以经过反相器的路径比直接到与门的路径慢，这就是静态冒险。触发器只在时钟边沿动作（可选上升 / 下降沿），D 锁存器在 EN = 1 时透明。一根线有两个输出驱动且值不同显示红色 X，没有驱动的输入按 0 处理并在提示行里列出来。

    智能功能：「真值表」对每个 LED 给出 Σm、最小和、最小积、卡诺图（彩色圈出每个乘积项、标出本质质蕴含项）、静态 1 冒险和要补的冗余项，还能找出最长的门延迟路径；按钮可以把当前电路换成最小和 / 全与非 / 全或非实现。「状态图」枚举所有触发器状态和输入，画出状态转换图和状态表，判断 Moore / Mealy，标出用不到的状态和锁死的状态。「生成电路」支持表达式、Σm / ∏M（含无关项）和可编辑的真值表。

    可以试：冒险预设里打开「BC项」开关，毛刺消失（真值表页会告诉你要补的就是 BC）；环形计数器预设直接打开状态图，看 000 等状态的锁死；4 位计数器里数码管会从 0 数到 F；在「生成电路」输入 F = A'B + AC 选「无冒险 SOP」，比较生成的电路多了哪一项。快捷键：空格 运行 / 暂停，. 单步，Ctrl Z / Y 撤销 / 重做，Ctrl C / V / D 复制 / 粘贴 / 复制一份，Delete 删除，Esc 回到选择。
